Pet-проект "Социальная сеть", реализованный с использованием ASP.NET Core Web API. Поддерживает регистрацию, авторизацию, создание постов, подписки на пользователей, лайки и комментарии.

Используемые технологии:

ASP.NET Core — основной backend-фреймворк

PostgreSQL — реляционная СУБД для хранения данных

Redis — кэширование и возможное хранение токенов

Swagger — интерактивная документация API

Docker — контейнеризация приложения

DBeaver — инструмент для работы с базой данных
